# SpecFlow — Claude Code

This project uses **SpecFlow** for spec-driven multi-agent development.

## Required on every turn

Before responding, read and follow **`.agents/rules/orchestrator.md`**.

The orchestrator routes to Refiner, SDD, Implementer, or Reviewer based on `.agents-state/current/phase.md`.

## Activation

- Start flow: `nueva tarea`, `activar flujo`, `flow on`
- End flow: `modo directo`, `flow off`, `desactivar flujo`

Full documentation: `AGENTS.md`
